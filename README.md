# はめ あそび (hame-asobi)
型はめ（形の弁別・見比べ）を、画面で練習する遊び。
参考：療育の実践書（「型はめ」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。
- `public/index.html` 単一ファイル。Cloudflare Workers（assets）で公開。
- 場面: 型はめ（部品2/3/4/6、形 丸四角→三角→星）／絵パズル（ピース2/4、絵5種）。手助け 大/ふつう/小。
- 失敗の音・揺れなし（静かに戻る）。成功は「ことん」＋星。お祝いの強さは調整可。
- 記録・名前・声・顔は保存しない。カメラ・マイク不使用。設計: docs/spec.md
