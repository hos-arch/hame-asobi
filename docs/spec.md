# はめ あそび 仕様（hame-asobi）（確定案・初版）

## 0. 設計思想（開発中の判断基準）
**子どもに正解させるアプリではなく、子どもが自分から何度も試したくなるアプリにする。** 形を見分け、選び、試して、はめる、という操作そのものを楽しむ。完成は目的ではなく、結果。迷ったときは、この基準で決める。

## 1. 要約
型はめパズルを、画面で行うWebアプリにする。参考：療育の実践書（「形を選んではめる操作」の課題を参考にした）。この仕様は、同書の考え方をもとに、私たちが画面用に解釈した試作です。
- 形を選んではめる（型はめ）：穴の形に合う部品を選んで入れる
- 絵をはめる（絵パズル）：絵を切ったピースを、元の場所に戻す（絵は初期認知の範囲の日用品。さす あそび・てあそび と同じ5つ）
子どもが自分で選び、入れ、できたら喜べる遊び。繰り返し使う前提で、やさしい手助けと、ゆるやかな段階を用意する。

## 2. 目的（支援者向け）
- 形や絵を選んではめる操作の練習（目と手の協応）。「できた」を繰り返し体験する
- 支援者が、子どもの様子（選ぶ、迷う、手を出す、待つ）を見て、次の段階を決める手がかりにする

## 3. 画面（子どもの画面は文字なし）
### 場面
- 型はめ：穴板（円・三角・四角・星）。部品は、板の上の列に並ぶ。部品の形と穴の形を合わせると、穴の中へ「ことん」と入る
- 絵パズル：枠の中に絵（くるま・りんご・バナナ・さかな・おはな）。ピースを、枠の中の正しい場所へ戻す

### 操作
- 部品（ピース）を指でつかみ、穴（枠の場所）の上で離す
- 合えば、ことんと入り、星が出る。音は高くなっていく（入れるたびに）
- 合わなければ、部品は元の場所へ戻る（いやな音は出さない。ふわっと戻る）
- ぜんぶ入ると、お祝い（強さは支援者が選ぶ）。少しして、次の型・絵へ。入れた数は画面に出さない

### 段階（支援者メニューの「この場面」）
- 型はめ：部品の数 2／3／4／6。形の種類は「円と四角」→「円・四角・三角」→「円・四角・三角・星」の3段階（固定の発達段階ではなく、遊びながら支援者が選べる難易度）。最初は「円と四角」
- 絵パズル：ピースの数 2／4（絵は5種から、順番に出す）。ピース数を増やすより、「ひとつのピースの細部から全体が思い浮かぶ」構成にする（できなかったことを手伝って次の段階へ進む、最近接領域の考え方）
- ヒント：出す／出さない（出すと、手助けに応じて、正しい穴がゆっくり光る）

### 手助け（みんな共通）：入る範囲と、見た目の補助、の両方を変える
- 大きい：穴の近くで離せば、ほぼ入る。正しい穴が、最初からやわらかく光っている。一定時間入らないと、その光がゆっくり強まる
- ふつう：穴の中心に近いところで離すと入る。少し待つと、正しい穴が光る
- 小さい：ピースを穴の中心にぴったり合わせて離す。光は出ない（自分で探す）。ヒントは、支援者が出した時だけ

### 反応（失敗を強調しない）
- 合わないとき：「違う」を示す音・絵・揺れは出さない。部品が静かに、元の場所へ戻る
- 合うとき：穴に、ことんと沈む（小さく弾み、星が1つ出て、音が上がる）。入ったことが、はっきり感じられる動きにする

## 4. 支援者メニュー（案B、右上の点を1.2秒長押し）
- 場面（型はめ／絵パズル）
- この場面：部品の数、形の種類（型はめ）、ピースの数（絵パズル）、ヒント（出す／出さない）
- みんな共通：手助け（大・ふつう・小）
- くわしく：触れ方（最初の指だけ／どの指でも）、見た目（やさしい／ふつう／はっきり）、音（なし／小／中／大）、お祝いの強さ（なし／控えめ（初期値）／ふつう／派手）、説明をもう一度
- もとにもどす／とじる。「とめる」「おしまい」は、既存の他アプリと同じ位置

## 5. 音・見た目
- 入るとき：ペンタトニックの音（入れる数で上がる）。完成は、ベルのアルペジオ
- 色は、既存アプリ（かく・さす・はこ）と同じ、やわらかい手描き風の色
- 点滅なし。急な音なし。音量は支援者が調節

## 6. 約束（既存アプリと同じ）
- 子どもの名前・記録・声・顔・録音は保存しない。カメラ・マイクは使わない
- 画面に文字を出さない（子どもの画面）。支援者用の説明画面にだけ文字
- 治療効果をうたわない
- 画面の向きが変わっても、進行中の型・絵は残す

## 7. 観察（決定：案A）
- アプリには、記録を一切残さない。支援者が、紙に書く
- 理由：子どもが評価されていると感じない環境にする／支援者が画面や記録に気を取られない／目的を、遊びと支援に置く
- 将来、観察の機能が必要になったときは、別の仕組みとして足せる余地を残す（今は作らない。保存もしない）

## 8. 作る順
1. 型はめ（円と四角→三角→星、部品2〜6）。操作性と難易度調整を確かめる
2. 手助け（入る範囲＋光）、静かに戻す反応、お祝い（既存の「お祝いの強さ」を流用）
3. 動作確認（iPad縦横・iPhone・SE）、GitHub（hos-arch/hame-asobi）、Cloudflare
4. その後に、絵パズル（ピース2〜6）

## 9. 決定事項（2026-11-03）
1. 観察記録：案A（保存しない）
2. アプリ名：はめ あそび（hame-asobi）
3. 開発順：型はめ → 絵パズル
4. 形の難易度：3段階（円と四角／＋三角／＋星）。支援者が選べる
5. 失敗時：静かに元の場所へ戻す
6. 手助け：入る範囲と、光の補助量の両方を変える
7. お祝い：既存の「お祝いの強さ」（なし／控えめ（初期値）／ふつう／派手）を流用。輪と閃光は「派手」のときだけ

## 10. 実装メモ（v1）
- 実装済み：型はめ（部品2/3/4/6、形 丸四角→＋三角→＋星、手助け 大/ふつう/小、ヒント 出す/出さない、「ヒントを今出す」「つぎの型にする」、お祝い強さ、触れ方、見た目、音）。
- 大きい：入れる範囲 2.2倍・板の上ならどこで離しても合う穴へ・穴が常にやわらかく光る／ふつう：10秒待つと穴が光る／小さい：光らず、部品は同じ色。
- 違う穴の上で離すと、約0.35秒とどまって静かに戻る（音・揺れなし）。入った部品は、つまみ直して出せる。
- 全部入ると、お祝い→新しい型。絵パズルは未実装（次）。
- 確認：Playwright（iPad縦横・iPhone縦横・SE）で全構成の完走・誤り戻し・エラーなし。実機iPhoneは未確認。

## 11. 実装メモ（v2：絵パズル）
- 場面に「絵パズル」を追加（支援者メニュー「この場面」→ 場面）。ピースの数は 2／4 の2段階。6ピースは、1つ1つに絵の細部が入らず全体を予想しにくいので、やめた（2026-11-03 決定）。
- 絵は5種（車・りんご・バナナ・さかな・はな）。図形だけで、正方形の枠いっぱいに描く（背景も全面に塗る。白い余白を作らない）。同じ絵が続けて出ないようにする。
- 2ピースは左右に半分ずつ、4ピースは2×2に切る。向きに関係なく、同じ切り方。
- ピースは枠の中の正しい場所だけに入る。手助け・ヒント・お祝い・静かな戻り方は型はめと同じ。大きい手助けでは、板の上ならどこで離しても、空いている正しい枠へ入る。
- ピースの縁取りは、型はめより少し強くする（背景と区別するため）。
- 未決：手助け「大きい」「ふつう」で、枠に絵の全体を薄く出すか（案B）。
- 確認：Playwright（iPad縦横・iPhone縦横・SE）で、2／4のピース、3種の手助け、誤った枠からの静かな戻り、型はめの回帰テストが全て通過。エラーなし。実機iPhoneは未確認。

## 12. 写真からのパズル（2026-11-03 決定・実装）
- 絵パズルの「絵の出どころ」：「いつもの絵」／「写真」。支援者メニュー（この場面）で、「写真を選ぶ」から、端末の写真（カメラロール）を選ぶ。
- 写真は、ピースの並びの比率（2ピースは横2:縦1、4ピースは正方形）に合わせて、中央から切り抜く。
- 写真は、この画面の中だけで使う。保存も、外への送信もしない。ページを閉じる・再読み込みすると消える。「写真を消す」でも消せる。
- 子どもの写真や家の中が写る場合があるので、支援者が使う写真を選ぶ（おもちゃが中央に写り、背景がすっきりしたものが分かりやすい）。
- 確認：Playwright で、写真の読み込み→2ピースを全て正しい枠へ→完成、を確認。写真の2ピースは正方形になり、歪まない。実機iPhoneでの写真選択（HEIC含む）は未確認。
